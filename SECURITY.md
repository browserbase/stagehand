# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Report them privately in one of these ways:

- Email [security@browserbase.com](mailto:security@browserbase.com). You can encrypt your report with our
  [PGP key](https://www.browserbase.com/.well-known/pgp-publickey.txt).
- Use GitHub's [private vulnerability reporting](https://github.com/browserbase/stagehand/security/advisories/new).

Please include the affected package and version, steps to reproduce, and the impact you observed.

## Supported versions

We fix security issues in the latest release of each published package: `@browserbasehq/stagehand` on npm,
`stagehand` on PyPI, the Go module, and the `browse` CLI.
