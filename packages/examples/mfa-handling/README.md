# mfa-handling

TOTP demonstration against a public authentication test site, with demo values discovered at runtime.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root          |
| ---------------------------------- | -------------------- | ------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/mfa-handling/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/mfa-handling/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
