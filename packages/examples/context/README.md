# context

Public recreation-site context reuse; login values are supplied at runtime, with no bundled account state.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root     |
| ---------------------------------- | -------------------- | -------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/context/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/context/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
