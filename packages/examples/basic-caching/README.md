# basic-caching

Observe/cache example on the reserved example.com domain.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root           |
| ---------------------------------- | -------------------- | -------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/basic-caching/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/basic-caching/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
