# smart-fetch-scraper

Fetch-first extraction with a meaningful Stagehand browser fallback.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                 |
| ---------------------------------- | -------------------- | -------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/smart-fetch-scraper/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/smart-fetch-scraper/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
