# proxies-weather

Public weather extraction with proxy geography configuration.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root             |
| ---------------------------------- | -------------------- | ---------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/proxies-weather/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/proxies-weather/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
