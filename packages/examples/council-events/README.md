# council-events

Read-only extraction of public Philadelphia council calendar records.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root            |
| ---------------------------------- | -------------------- | --------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/council-events/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/council-events/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
