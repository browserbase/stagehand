# amazon-global-price-comparison

Public product search across storefronts with configurable product input; no customer account data.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                            |
| ---------------------------------- | -------------------- | ------------------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/amazon-global-price-comparison/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/amazon-global-price-comparison/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
