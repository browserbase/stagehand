# job-application

Dedicated agent job-board demo with generated example.com addresses and an agent resume, not a customer ATS.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root             |
| ---------------------------------- | -------------------- | ---------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/job-application/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/job-application/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
