# basic-recaptcha

Stagehand actions against the public reCAPTCHA demo.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root             |
| ---------------------------------- | -------------------- | ---------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/basic-recaptcha/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/basic-recaptcha/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
