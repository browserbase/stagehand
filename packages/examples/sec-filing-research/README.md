# sec-filing-research

Public SEC filings research using sample public-company identifiers.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                 |
| ---------------------------------- | -------------------- | -------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/sec-filing-research/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/sec-filing-research/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
