# polymarket-research

Read-only public prediction-market research.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                 |
| ---------------------------------- | -------------------- | -------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/polymarket-research/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/polymarket-research/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
