# browserbase-reducto

Public Apple investor documents downloaded with Stagehand and parsed with Reducto; keys come from the environment.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                 |
| ---------------------------------- | -------------------- | -------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/browserbase-reducto/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/browserbase-reducto/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
