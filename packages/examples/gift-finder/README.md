# gift-finder

Public retail product recommendations with configurable recipient interests.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root         |
| ---------------------------------- | -------------------- | ------------------------------------------ |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/gift-finder/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/gift-finder/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
