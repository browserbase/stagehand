# manual-mfa-with-contexts

Generic GitHub login with interactive user authentication and fresh runtime contexts.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                      |
| ---------------------------------- | -------------------- | ------------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/manual-mfa-with-contexts/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/manual-mfa-with-contexts/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
