# proxies

Stagehand extraction from public IP-information endpoints.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root     |
| ---------------------------------- | -------------------- | -------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/proxies/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/proxies/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
