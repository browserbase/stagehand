# website-link-tester

Public website link checking using Stagehand extraction and configurable target URL.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                 |
| ---------------------------------- | -------------------- | -------------------------------------------------- |
| [TypeScript](typescript/README.md) | `4.0.2`              | `packages/examples/website-link-tester/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/website-link-tester/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
