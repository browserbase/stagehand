# amazon-product-scraping

Structured extraction from public product search results.

Choose a language and follow its setup instructions:

| Language                           | Stagehand dependency | Directory from the repository root                     |
| ---------------------------------- | -------------------- | ------------------------------------------------------ |
| [TypeScript](typescript/README.md) | `4.0.0`              | `packages/examples/amazon-product-scraping/typescript` |
| [Python](python/README.md)         | `4.0.0`              | `packages/examples/amazon-product-scraping/python`     |

Each variant installs the published Stagehand package and keeps its own dependencies.
