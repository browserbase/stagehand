# Browserbase skills

Skills are maintained in [browserbase/skills](https://github.com/browserbase/skills).

- [Framework and tooling skills](https://github.com/browserbase/skills/tree/main/skills)
- [Website and task skills from browse.sh](https://github.com/browserbase/skills/tree/main/browser-skills)
- [Browse.sh live catalog](https://browse.sh)

Use `npx skills add browserbase/skills --list` to discover the available skills. The website/task collection is tracked in a separate skills-repository change and becomes available from `main` after that change is merged.
