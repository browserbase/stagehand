Stagehand provides a typed browser automation API with matching TypeScript and Python clients.
Use the native view selector on each page to switch between language-specific examples and signatures.

## Install and initialize

<View title="TypeScript" icon="js">

**Install**

```bash
pnpm add @browserbasehq/stagehand
```

**Initialize Stagehand**

```typescript
import { localBrowser, Stagehand } from "@browserbasehq/stagehand";

const browser = await localBrowser.launch();
try {
  const stagehand = await Stagehand.create({ browser });
  try {
    const [page] = await browser.context.pages();
    await page.goto("https://example.com");
  } finally {
    await stagehand.close();
  }
} finally {
  await browser.close();
}
```

</View>

<View title="Python" icon="python">

**Install**

```bash
pip install stagehand
```

**Initialize Stagehand**

```python
import asyncio

from stagehand import Stagehand, local_browser


async def main() -> None:
    browser = await local_browser.launch()
    try:
        stagehand = await Stagehand.create(browser=browser)
        try:
            page = (await browser.context.pages())[0]
            await page.goto("https://example.com")
        finally:
            await stagehand.close()
    finally:
        await browser.close()


asyncio.run(main())
```
