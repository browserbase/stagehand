Send Stagehand browser traces to Langfuse through its OTLP/HTTP endpoint. Stagehand exports directly from the browser runtime, without a Langfuse SDK.

## Setup

1. Copy your Langfuse project's public and secret keys.
2. Set `BROWSERBASE_API_KEY`, `LANGFUSE_PUBLIC_KEY`, and `LANGFUSE_SECRET_KEY`.
3. Set `LANGFUSE_BASE_URL` for your deployment. The examples default to EU Cloud.

| Deployment | Base URL |
| --- | --- |
| EU | `https://cloud.langfuse.com` |
| US | `https://us.cloud.langfuse.com` |
| Japan | `https://jp.cloud.langfuse.com` |
| HIPAA | `https://hipaa.cloud.langfuse.com` |

For self-hosted Langfuse, use your instance's URL. The OTLP endpoint requires version 3.22.0 or later.

Authentication is Basic Auth with the base64-encoded `public:secret` key pair. Include `x-langfuse-ingestion-version: 4` for real-time v4 ingestion. Without it, direct OTLP data can take up to 10 minutes to appear. See [Langfuse's OpenTelemetry documentation](https://langfuse.com/integrations/native/opentelemetry).

## Configure Stagehand

These examples use the [v4 SDK](/v4/first-steps/installation) with a Browserbase browser. The exporter runs inside the browser extension, so the endpoint must be reachable from that browser.

<Tabs>
<Tab title="TypeScript">
```typescript
import { browserbase, Stagehand } from "@browserbasehq/stagehand";

const browser = await browserbase.launch({ apiKey: process.env.BROWSERBASE_API_KEY! });
try {
  const stagehand = await Stagehand.create({
    browser,
    telemetry: {
      traces: {
        endpoint: `${(process.env.LANGFUSE_BASE_URL ?? "https://cloud.langfuse.com").replace(/\/$/, "")}/api/public/otel/v1/traces`,
        headers: {
          "Authorization": `Basic ${Buffer.from(`${process.env.LANGFUSE_PUBLIC_KEY}:${process.env.LANGFUSE_SECRET_KEY}`).toString("base64")}`,
          "x-langfuse-ingestion-version": "4",
        },
      },
    },
  });
  try {
    const [page] = await browser.context.pages();
    await page.goto("https://example.com");
    await stagehand.observe("find the link on the page");
  } finally {
    await stagehand.close();
  }
} finally {
  await browser.close();
}
```

<Tab title="Python">
```python
import asyncio
import base64
import os

from stagehand import Stagehand, browserbase


async def main():
    browser = await browserbase.launch(api_key=os.environ["BROWSERBASE_API_KEY"])
    try:
        stagehand = await Stagehand.create(
            browser=browser,
            telemetry={
                "traces": {
                    "endpoint": f"{os.environ.get('LANGFUSE_BASE_URL', 'https://cloud.langfuse.com').rstrip('/')}/api/public/otel/v1/traces",
                    "headers": {
                        "Authorization": "Basic " + base64.b64encode(f"{os.environ['LANGFUSE_PUBLIC_KEY']}:{os.environ['LANGFUSE_SECRET_KEY']}".encode()).decode(),
                        "x-langfuse-ingestion-version": "4",
                    },
                },
            },
        )
        try:
            page = (await browser.context.pages())[0]
            await page.goto("https://example.com")
            await stagehand.observe("find the link on the page")
        finally:
            await stagehand.close()
    finally:
        await browser.close()


asyncio.run(main())
```

Close Stagehand before closing the browser to flush pending spans. Exports run in one-second batches; exiting without closing Stagehand can lose the final batch. Delivery is best effort, so successful cleanup does not confirm ingestion.

## Verify traces

Open Tracing in the project associated with your keys. Find the operation and log spans from the run. Stagehand does not emit Langfuse session attributes or GenAI generation attributes, so these spans do not automatically include session grouping, model token usage, or cost fields.

If the project is empty, check the region, the Basic Auth key order, the ingestion-version header, and that Stagehand closed before the browser.
