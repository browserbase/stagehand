**Goal:** Show how Stagehand and [OpenRouter](https://openrouter.ai) fit together — call any OpenRouter model from a custom Stagehand LLM callback, then automate [stagehand.dev](https://stagehand.dev).

**Outcome:** A TypeScript sketch that points an OpenAI-compatible client at OpenRouter, plugs it into `Stagehand.create`, and runs extract → act → observe on stagehand.dev. Change one model string to switch providers.

## Agent brief

Give this section to your coding agent as the implementation brief. It should adapt the model callback and task rather than scaffold a separate app.

```text
Build a Stagehand v4 script that routes its LLM calls through OpenRouter.

Stack: Node.js 18+, @browserbasehq/stagehand, zod, openai SDK as an
OpenRouter client. Browser: Browserbase via BROWSERBASE_API_KEY.
Model: any OpenRouter model string (e.g. google/gemini-3.1-flash-lite).

Architecture rules:
- Point the OpenAI SDK at https://openrouter.ai/api/v1.
- Pass a generate callback into Stagehand.create({ browser, model }).
  Align its shape with LLMGenerateParams — mirror
  packages/sdk-ts/examples/customLlm.ts for message/responseFormat
  mapping. Stagehand never talks to OpenRouter directly.
- Changing providers must be a one-line MODEL constant change.
- Flow: goto stagehand.dev → extract value prop (zod schema) → act on
  Evals button → observe available actions.

Verify: extraction returns parsed structured data through OpenRouter,
and switching the MODEL string reruns without other edits.
```

## Stack

- Node.js 18+
- `@browserbasehq/stagehand`, `zod`, and `openai` (OpenAI SDK as an OpenRouter client)
- `BROWSERBASE_API_KEY` for the browser
- `OPENROUTER_API_KEY` for the model

## Full script

```typescript
import OpenAI from "openai";
import { browserbase, Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod/v4";

// Swap this string to change providers via OpenRouter.
const MODEL = "google/gemini-3.1-flash-lite";
// Other examples:
// - openai/gpt-chat-latest
// - anthropic/claude-sonnet-4

const openrouter = new OpenAI({
  apiKey: process.env.OPENROUTER_API_KEY,
  baseURL: "https://openrouter.ai/api/v1",
});

/**
 * Illustrative generate callback: forward Stagehand's structured request
 * to OpenRouter. Map messages / responseFormat the way
 * packages/sdk-ts/examples/customLlm.ts does for OpenAI Responses.
 */
async function generateWithOpenRouter(params: {
  systemPrompt?: string;
  messages: { role: string; content: unknown }[];
  responseFormat?: { type: string; name: string; schema: unknown };
}) {
  const completion = await openrouter.chat.completions.create({
    model: MODEL,
    messages: [
      { role: "system", content: params.systemPrompt ?? "" },
      ...params.messages.map((m) => ({
        role: m.role as "user" | "assistant" | "system",
        content:
          typeof m.content === "string" ? m.content : JSON.stringify(m.content),
      })),
    ],
  });

  const text = completion.choices[0]?.message?.content ?? "";
  return {
    role: "assistant" as const,
    content: { type: "text" as const, text },
    outputFormat: "json_schema" as const,
    structuredContent: JSON.parse(text),
  };
}

async function main() {
  const browser = await browserbase.launch({
    apiKey: process.env.BROWSERBASE_API_KEY,
  });

  try {
    const stagehand = await Stagehand.create({
      browser,
      // Illustrative: align generateWithOpenRouter with LLMGenerateParams in production
      model: { generate: generateWithOpenRouter },
    });

    try {
      const [page] = await browser.context.pages();
      await page.goto("https://stagehand.dev");

      const { data: pitch } = await stagehand.extract(
        "Extract the value proposition from the page.",
        z.object({ valueProposition: z.string() }),
      );
      console.log("Value proposition:", pitch.valueProposition);

      await stagehand.act("Click the 'Evals' button.");

      const { data: actions } = await stagehand.observe(
        "What can I click on this page?",
      );
      console.log("Observed actions:", actions);
    } finally {
      await stagehand.close();
    }
  } finally {
    await browser.close();
  }
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

Run with both keys set:

```bash
export BROWSERBASE_API_KEY="your-browserbase-api-key"
export OPENROUTER_API_KEY="sk-or-v1-..."
npx tsx chat-and-browser.ts
```

## Walkthrough

1. **OpenRouter as the LLM** — Point the OpenAI SDK at `https://openrouter.ai/api/v1` and pass a `generate` callback into `Stagehand.create`. Stagehand never talks to OpenRouter directly.
2. **One model string** — Changing `MODEL` switches providers on OpenRouter without rewriting the automation.
3. **Same primitives** — The browser flow matches [First automation](/v4/examples/get-started/first-automation); only model routing differs.
4. **Gateway alternative** — On Browserbase you can omit `model` and use [Model Gateway](/v4/configuration/models) when you want Browserbase to select and bill the model instead.

## Check your work

- The generate callback returns the shape Stagehand expects (assistant role, text content, `json_schema` output format) — check it against `LLMGenerateParams`, not just the sketch.
- Extraction returns parsed structured data, proving schema-bearing requests survive the OpenRouter hop.
- Changing only `MODEL` switches providers end-to-end.
- Both `BROWSERBASE_API_KEY` and `OPENROUTER_API_KEY` come from the environment.
