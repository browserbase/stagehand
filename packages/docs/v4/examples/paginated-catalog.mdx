## Goal and output

Export the [Books to Scrape](https://books.toscrape.com/) catalog into `out/catalog.json`. Each entry has a nonempty title, displayed price, and availability. The file also reports `pages` and `count`. A page limit or broken pagination fails before writing a partial file.

## Prerequisites and inputs

- Add `BROWSERBASE_API_KEY` and `OPENAI_API_KEY` to `.env`. These folders use OpenAI as the example model provider. Set `MODEL_PROVIDER=gateway` to use [Browserbase Model Gateway](/v4/configuration/models#model-gateway) without a separate model key, or adapt the [model configuration](/v4/configuration/models) for another provider.
- `CATALOG_URL` defaults to `https://books.toscrape.com/`. `MAX_PAGES` defaults to 50 and must be a positive integer.
- TypeScript needs Node.js 22.18+ and pnpm; Python needs Python 3.11+ and uv; Go needs Go 1.26+.

## How the job works

1. Launch one cloud browser and navigate to `CATALOG_URL`. Keep the same page for all extraction and navigation calls.
2. Check the current URL against a visited set. Extract all visible books into a typed schema with nonempty fields.
3. Ask `observe()` for the enabled Next link. If it returns no action, the catalog is complete. Otherwise, pass the returned Action to `act()` and require a new URL.
4. Fail at `MAX_PAGES` when a Next action still exists. Write the file only after natural completion, then close Stagehand and the browser.

The extraction schema checks each page before the code looks for Next:

```typescript
const result = await stagehand.extract(
  "Extract every book in the product grid with its title, price, and availability.",
  pageSchema,
  { page },
);
books.push(...pageSchema.parse(result.data).books);

const next = (await stagehand.observe(
  "Find the enabled Next pagination link. Return no action on the last page.",
  { page },
)).data[0];

if (next) {
  const acted = await stagehand.act(next, { page });
  if (!acted.data.success) {
    throw new Error(acted.data.message);
  }
}
```

## Expected result and failure checks

A completed run prints `Saved N books from P pages to out/catalog.json`. The file contains `pages`, `count`, and `books`; `count` equals the array length. Set `MAX_PAGES=1` against a multipage catalog to confirm the limit fails without producing output. A one-page fixture stops when Next is absent. A cycle or unchanged URL fails instead of looping.
