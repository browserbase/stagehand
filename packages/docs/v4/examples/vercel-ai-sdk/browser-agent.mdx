**Goal:** Drive [stagehand.dev](https://stagehand.dev) with a Vercel AI SDK agent that keeps one Stagehand browser alive across `run`, `snapshot`, and `screenshot` tool calls.

**Outcome:** An agent that opens the site, extracts the value proposition, clicks into Evals, and reports what it found — without reconnecting the browser on every step.

## Agent brief

Give this section to your coding agent as the implementation brief. It should adapt the example names and task rather than scaffold a separate app.

```text
Build a browser agent with Stagehand v4 and the Vercel AI SDK (v7).

Stack: Node.js 24+, pnpm, ai@^7, @ai-sdk/openai,
Stagehand facade MCP server from @browserbasehq/stagehand-integrations.
Browser: local Chrome by default; BROWSERBASE_API_KEY switches to cloud.

Architecture rules:
- ONE facade MCP client session for the whole agent loop. Page state,
  cookies, and tabs must survive every tool call. Close it only after
  generateText finishes.
- Load the three Stagehand tools — snapshot (a11y tree), run
  (Playwright-shaped JS), screenshot — via client.tools().
- Use ToolLoopAgent or generateText with instructions from
  FACADE_AGENT_INSTRUCTIONS; stopWhen: stepCountIs(20).
- Task must chain tools (navigate → extract → click → summarize) so the
  agent cannot answer from training data alone.

Task: open stagehand.dev, extract the value proposition, click Evals,
summarize what a visitor can do there.

Verify: output mentions Evals content AND exactly one browser session
was created (no reconnection mid-run).
```

<Note>
  This is a cookbook-shaped recipe. For clone-and-run wiring, see the [Vercel AI SDK integration](/v4/integrations/vercel-ai-sdk). Stagehand ships this experimental adapter from the monorepo; it is not a standalone npm package yet.
</Note>

## Stack

- Node.js 24+ and pnpm
- Vercel AI SDK (`ai`, `@ai-sdk/openai`)
- Stagehand facade MCP server (`@browserbasehq/stagehand-integrations`)
- `OPENAI_API_KEY` for the agent model
- Local Chrome or `BROWSERBASE_API_KEY` for the browser

## Full script

The integration example connects once, loads the three Stagehand tools, and runs a multi-step `generateText` loop. Point the prompt at stagehand.dev instead of a one-shot title check:

```typescript
import { openai } from "@ai-sdk/openai";
import { FACADE_AGENT_INSTRUCTIONS } from "@browserbasehq/stagehand-integrations/facade";
import { generateText, stepCountIs, type ToolSet } from "ai";

import { createFacadeMCPClient } from "./client.ts";

async function main() {
  const client = await createFacadeMCPClient();

  try {
    const result = await generateText({
      model: openai(process.env.AI_SDK_STAGEHAND_MODEL ?? "gpt-5.6-luna"),
      tools: (await client.tools()) as ToolSet,
      stopWhen: stepCountIs(20),
      instructions: FACADE_AGENT_INSTRUCTIONS,
      prompt: [
        "Open https://stagehand.dev.",
        "Extract the value proposition from the homepage.",
        "Click the Evals button.",
        "Summarize what a visitor can do on the Evals page.",
      ].join(" "),
    });

    console.log(result.text);
  } finally {
    await client.close();
  }
}

main().catch((error: unknown) => {
  console.error(error instanceof Error ? error.message : error);
  process.exitCode = 1;
});
```

Run from the Stagehand monorepo after building integrations:

```bash
export OPENAI_API_KEY="your-openai-api-key"
# Optional: cloud browser
# export STAGEHAND_BROWSER="browserbase"
# export BROWSERBASE_API_KEY="your-browserbase-api-key"

pnpm --dir packages/integrations/vercel-ai start -- \
  "Open https://stagehand.dev, extract the value proposition, click Evals, and summarize the page."
```

## Walkthrough

1. **One MCP client session** — `createFacadeMCPClient` starts the Stagehand facade over stdio. Keep that client open for the whole agent loop so page state survives every tool call.
2. **Three tools** — The model uses `snapshot` (accessibility tree), `run` (Playwright-shaped JS or snapshot actions), and `screenshot`. See the [tool contract](/v4/integrations/overview#tool-contract).
3. **Multi-step prompt** — Ask for extract → click → summarize on stagehand.dev so the agent must chain tools instead of answering from training data.
4. **Close once** — Call `client.close()` only after `generateText` finishes. Reconnecting mid-task starts a new browser and drops cookies, tabs, and history.

<Warning>
  `run` executes model-authored JavaScript in the browser. Prefer Browserbase for untrusted tasks and review the [integration security boundary](/v4/integrations/overview#security-boundary).
</Warning>

## Check your work

- Exactly one browser session exists for the whole run — no reconnect between steps.
- The agent used `snapshot` before acting (it read the page, not guessed).
- Output references Evals page content that is not derivable from the homepage alone.
- `client.close()` runs after the loop finishes, including on errors.
