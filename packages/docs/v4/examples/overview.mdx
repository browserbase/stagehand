These are complete Stagehand programs built with common tools and frameworks. The integration pages explain how to connect a stack. These examples show what to build after that.

When Codex, Claude Code, or another coding agent searches the Stagehand docs, these pages provide working patterns with code, inputs, and checks.

Each recipe defines when the job stops, how it cleans up, and what to check after you adapt it.
