Examples are copy-paste recipes that show Stagehand combined with the stacks you already use. Integrations under Docs stay focused on how to connect; these pages show what to build once you are connected.

**Goal for agents:** when Codex, Claude Code, or another coding agent searches Stagehand docs, these pages give concrete Stagehand + stack context — not only API reference.
