Stagehand cookbooks show how to use the SDK to complete browser tasks and connect Stagehand to other tools. Each cookbook page includes a prompt you can give to a coding agent, setup and run instructions, an explanation of the approach, and checks for common failures. The matching source folder contains the runnable project.

Browse the cookbooks in the navigation, then choose the language and setup described on that page. Cookbooks may use different browser types, model providers, and integrations. See [model configuration](/v4/configuration/models) for provider options.

| Cookbook | Use it when | Inputs | Output | Stagehand methods | Languages |
| --- | --- | --- | --- | --- | --- |
| [Approve a form submission](/v4/cookbooks/approve-form-submission) | A browser action needs human consent | Test form values, approval answer | Submitted URL or a clear rejection | `act()` | TypeScript, Python, Go |
| [Export a paginated book catalog](/v4/cookbooks/paginated-catalog) | The number of result pages is unknown | Catalog URL, page limit | Validated `out/catalog.json` | `extract()`, `observe()`, `act()` | TypeScript, Python, Go |
| [Save extracted files to a bucket](/v4/cookbooks/files-to-bucket) | Extracted page data and downloaded bytes must reach object storage | Target page, optional S3 bucket | Local JSON and cover, optional bucket objects | `extract()` | TypeScript |
| [Build an AI SDK research agent](/v4/cookbooks/ai-sdk-research-agent) | An agent must research approved pages and cite sources | Research question, approved URLs | Typed report with source URLs | `extract()` | TypeScript |
| [Smoke-test WebMCP](/v4/cookbooks/webmcp-smoke-test) | A preview page registers tools for browser agents | Preview URL, tool name, tool input | Completed invocation or nonzero failure | `page.tools()` | TypeScript, Python, Go |

## Run a cookbook

Choose a cookbook folder in [`packages/cookbooks`](https://github.com/browserbase/stagehand/tree/main/packages/cookbooks), then check out that folder:

```bash
git clone --depth 1 --sparse https://github.com/browserbase/stagehand.git
cd stagehand
git sparse-checkout set packages/cookbooks/<cookbook-name>
```

Open the cookbook's README or docs page for its supported languages, required keys, install steps, and run command. Each cookbook folder contains its own source and configuration.

For individual SDK methods, start with the [Stagehand basics](/v4/basics/act).
