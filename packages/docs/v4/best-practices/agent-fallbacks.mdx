**Planned. Not available in Stagehand v4.**

The original pattern here caught a failing `act()` and handed the task to `stagehand.agent()` to discover the new path. Stagehand v4 has no agent, so there is nothing to fall back to.
</Warning>

## What to use instead

When a one-step action becomes multi-step after a UI change, recover with `observe()`. It re-reads the page and tells you what is there, which is the same information the agent would have used, without giving up control of the flow.

<View title="TypeScript" icon="js">
```typescript
// "Sign In" used to be a top-level button. It now lives behind an account menu.
try {
  await stagehand.act("click the Sign In button");
} catch (error) {
  // Re-read the page and look for the entry point
  const { data: candidates } = await stagehand.observe("find the account or profile menu");

  if (candidates.length === 0) throw error;

  await page.locator(candidates[0].selector).click();
  await stagehand.act("click the Sign In option in the menu");
}
```
</View>

<View title="Python" icon="python">
```python
# "Sign In" used to be a top-level button. It now lives behind an account menu.
try:
    await stagehand.act("click the Sign In button")
except Exception:
    # Re-read the page and look for the entry point
    candidates = (await stagehand.observe(instruction="find the account or profile menu")).data

    if not candidates:
        raise

    await page.locator(candidates[0].selector).click()
    await stagehand.act("click the Sign In option in the menu")
```
</View>

<View title="Go" icon="golang">
```go
// "Sign In" used to be a top-level button. It now lives behind an account menu.
if _, err := client.Act(ctx, "click the Sign In button", nil); err != nil {
	// Re-read the page and look for the entry point
	instruction := "find the account or profile menu"
	observed, observeErr := client.Observe(ctx, &instruction, nil)
	if observeErr != nil {
		return observeErr
	}
	if len(observed.Data) == 0 {
		return err
	}

	if err := page.Locator(observed.Data[0].Selector).Click(ctx, nil); err != nil {
		return err
	}
	if _, err := client.Act(ctx, "click the Sign In option in the menu", nil); err != nil {
		return err
	}
}
```
</View>

<Tip>
Turn on self-healing so `act()` recovers from stale selectors on its own before your fallback ever runs. It re-snapshots the page and retries once when a deterministic action fails.
</Tip>
