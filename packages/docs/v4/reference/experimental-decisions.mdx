  Experimental. The surface, its configuration, and its behavior may change between releases.
</Warning>

A decision model answers small typed questions ("which of these options", "yes or no") with
probabilities. It does not generate text, and it answers in a few hundred milliseconds. The
`experimentalDecisions` namespace runs `act()`, `observe()`, and `extract()` through such questions
and hands over to the ordinary LLM pipeline whenever the model is not confident, so results have the
same shape as the regular methods and are usually faster.

The namespace is opt-in twice: configure a provider when you create Stagehand, then call the methods
on the namespace. `act()`, `observe()`, and `extract()` on the Stagehand instance itself never use
the decision model. Calling a namespace method without the configuration fails with an error.

## Providers

| `provider` | Model (default) | Needs |
| --- | --- | --- |
| `"typesafe"` (default) | TypeSafe Jev (`jev-latest`) | `apiKey` |
| `"cloudflare"` | Cloudflare Clef (`clef`, or `clef-flash`) | `apiKey`, `accountId` |
| `"perplexity"` | Perplexity Decider (`pplx-decider-v1-27b`) | `apiKey` |
| `"openai"` | OpenAI Decisions API (`gpt-6-luna`) | `apiKey` with access to the Decisions preview |

Acceptance thresholds were tuned on TypeSafe Jev. Other providers answer the same questions through
the same validation, but their probabilities are not calibrated identically; measure on your own
pages before relying on them.

The instruction, descriptions of candidate elements built from the accessibility tree, and the page
URL without query string or fragment are sent to the provider. `extract()` also sends page or
extracted content. Values of `%variables%` are replaced by their placeholders.

## Quick start

```typescript
const stagehand = await Stagehand.create({
  browser,
  model: "openai/gpt-5.4-mini",
  experimentalDecisions: { provider: "typesafe", apiKey: process.env.TYPESAFE_API_KEY! },
});

await stagehand.experimentalDecisions.act("Click the sign in button");
const actions = await stagehand.experimentalDecisions.observe("Find the search field");
const product = await stagehand.experimentalDecisions.extract("Extract the product", ProductSchema);
```

## Configuration

Pass `experimentalDecisions` to `Stagehand.create()`.

<ParamField path="experimentalDecisions.provider" type='"typesafe" | "cloudflare" | "perplexity" | "openai"' optional>
  The decision-model provider. Defaults to `"typesafe"`.
</ParamField>

<ParamField path="experimentalDecisions.apiKey" type="string">
  The provider's API key.
</ParamField>

<ParamField path="experimentalDecisions.model" type="string" optional>
  The provider's model name. Defaults to the provider's default model.
</ParamField>

<ParamField path="experimentalDecisions.apiUrl" type="string" optional>
  An `https` endpoint that replaces the provider's default one.
</ParamField>

<ParamField path="experimentalDecisions.accountId" type="string" optional>
  The Cloudflare account id. Required for `"cloudflare"`.
</ParamField>

<ParamField path="experimentalDecisions.actConfidence" type="number" optional>
  Minimum confidence, from 0 to 1, to act on an answer. Defaults to `0.7`.
</ParamField>

<ParamField path="experimentalDecisions.llmFallback" type="boolean" optional>
  Whether to hand over to the LLM pipeline when the decision model is not confident. Defaults to `true`; with `false` the call fails instead.
</ParamField>

<ParamField path="experimentalDecisions.argumentLlm" type="boolean" optional>
  Whether a small LLM call may lift unquoted text to type from the instruction. Defaults to `true`.
</ParamField>

<ParamField path="experimentalDecisions.extract" type='"judge" | "pick"' optional>
  How `extract()` uses the decision model. `"pick"` (default) picks the elements holding each value and copies their text; `"judge"` keeps the LLM extraction and replaces only its completion check.
</ParamField>

<ParamField path="experimentalDecisions.targetReadiness" type="boolean" optional>
  Act as soon as the target is found and stable instead of waiting out the DOM-settle window. Defaults to `false`.
</ParamField>

<ParamField path="experimentalDecisions.tools" type="boolean" optional>
  Let `act()` invoke a WebMCP tool the page registered when the decision model is sure the tool is the request. Defaults to `false`.
</ParamField>

<ParamField path="experimentalDecisions.cacheCheck" type="boolean" optional>
  Ask the decision model whether a cached action's selector still points at a matching element before replaying it. Defaults to `false`.
</ParamField>

<ParamField path="experimentalDecisions.pageState" type="boolean" optional>
  Check for captchas, access-denied pages, and similar states when no target is found. Defaults to `true`.
</ParamField>

<ParamField path="experimentalDecisions.verify" type='"off" | "checks" | "full"' optional>
  Post-action checks. Defaults to `"checks"`.
</ParamField>

<ParamField path="experimentalDecisions.retryNoEffect" type="boolean" optional>
  Click the runner-up when an ambiguous click provably changed nothing. Defaults to `false`.
</ParamField>

<ParamField path="experimentalDecisions.focusFallback" type="boolean" optional>
  On very large pages, show the LLM the decision model's shortlist first. Defaults to `false`.
</ParamField>

## Quick start

```go
client, err := stagehand.Create(ctx, &stagehand.CreateOptions{
	Browser: browser,
	Model:   model,
	ExperimentalDecisions: &stagehand.ExperimentalDecisionsConfig{
		APIKey: os.Getenv("TYPESAFE_API_KEY"),
	},
})
if err != nil {
	return err
}

decisions := client.ExperimentalDecisions()
if _, err := decisions.Act(ctx, stagehand.ActInstruction("Click the sign in button"), nil); err != nil {
	return err
}
product, err := stagehand.ExperimentalDecisionsExtract[Product](ctx, decisions, "Extract the product", nil)
if err != nil {
	return err
}
fmt.Println(product.Data)
```

## ExperimentalDecisionsExtract()


</ParamField>

<ParamField path="instruction" type="string">

</ParamField>

<ParamField path="options" type="*StagehandClientExtractOptions" optional>
  The options of `Extract()`.
</ParamField>

<ResponseField name="result" type="(TypedExtractResult[T], error)">
