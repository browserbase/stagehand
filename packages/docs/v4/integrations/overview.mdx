Use Stagehand to bring browser automation into the tools you already use. Connect an agent to a browser so it can work across websites, or call Stagehand from an application to automate a specific workflow.

The guides below cover setup, configuration, and working examples. Choose an integration based on what you want to connect.

## Automations

Use Stagehand directly from your application or script to automate a service's browser workflow. Your code controls the sequence of steps and can combine browser interactions with tools exposed by the page through [WebMCP](/v4/basics/webmcp).

## Build your own integration

Use the [Stagehand SDK](/v4/first-steps/quickstart) to add browser automation to your application. Combine [Act](/v4/basics/act), [Extract](/v4/basics/extract), and [Observe](/v4/basics/observe) with direct [page interactions](/v4/reference/page) to navigate, interact, and return structured data.

For pages that publish their own tools, use [WebMCP](/v4/basics/webmcp) to discover and invoke them. Choose a local browser or a Browserbase session in [browser configuration](/v4/configuration/browser).
