---
title: "Agno"
description: "Give an Agno agent persistent Stagehand browser tools over MCP/stdio."
---

The Agno integration connects a Python agent to the Stagehand facade MCP server using Agno's native `MCPTools` adapter. One server process owns the browser across `run`, `snapshot`, and `screenshot` calls.

<Note>
This experimental integration runs from the Stagehand repository. The example is tested with Agno 3.1.5.
</Note>

## Prerequisites

- Node.js 24 or newer
- pnpm 11.11.0
- Python 3.11–3.13
- [uv](https://docs.astral.sh/uv/)
- An OpenAI API key for the agent model
- A current Google Chrome installation for local browser mode

## Quickstart

<Steps>
  <Step title="Clone and build Stagehand">
```bash
git clone https://github.com/browserbase/stagehand.git
cd stagehand
pnpm install --frozen-lockfile
pnpm exec turbo run build \
  --filter @browserbasehq/stagehand-integrations
```
  </Step>
  <Step title="Install the Agno example">
```bash
cd packages/integrations/agno
uv sync --locked
```
  </Step>
  <Step title="Configure the agent model">
```bash
export OPENAI_API_KEY="your-openai-api-key"
```

The example uses OpenAI's `gpt-5.6-luna` by default. Set `AGNO_MODEL` to another OpenAI model ID. Use a vision-capable model when inspecting screenshots.
  </Step>
  <Step title="Choose the browser">
The integration uses Browserbase when `BROWSERBASE_API_KEY` is set, otherwise local Chrome. To select Browserbase explicitly:

```bash
export STAGEHAND_BROWSER="browserbase"
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```
  </Step>
  <Step title="Run a browser task">
```bash
uv run python agent.py \
  "Open https://example.com and report the page title."
```
  </Step>
</Steps>

## Configuration

| Variable | Purpose |
| --- | --- |
| `AGNO_MODEL` | OpenAI model ID for the Agno agent. |
| `OPENAI_API_KEY` | Agent model credential. The integration does not forward it to the MCP child. |
| `STAGEHAND_BROWSER` | Select `local` or `browserbase`. |
| `BROWSERBASE_API_KEY` | Required for Browserbase. When set, Browserbase is the default browser. |
| `BROWSERBASE_PROJECT_ID` | Optional Browserbase project ID. |
| `STAGEHAND_MODEL_NAME` | Optional model for Stagehand AI methods called inside `run`. |
| `STAGEHAND_MODEL_API_KEY` | Required with `STAGEHAND_MODEL_NAME`; the MCP child does not receive agent-provider credentials. |

## Screenshots and session lifetime

Agno's MCP adapter converts screenshot image blocks into images for the agent model. No temporary-file adapter is needed.

The example keeps one MCP connection open around the complete agent run. Keep that lifetime when adapting it: starting a new server for each tool call loses the browser and invalidates prior snapshot IDs.

<Warning>
`run` executes model-authored JavaScript in the browser. Use Browserbase for untrusted tasks and review the [integration security boundary](/v4/integrations/agent-frameworks/overview#security-boundary).
</Warning>
