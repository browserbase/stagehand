---
title: "Pydantic AI"
description: "Give a Pydantic AI agent persistent browser tools with stagehand-middleware."
---

The Pydantic AI integration registers native browser tools from `stagehand-middleware`. One browser stays open across `run`, `snapshot`, and `screenshot` calls. The middleware supplies the instructions, tool schemas, and browser behavior. Screenshots return native image content.

<Note>
The example is tested with Pydantic AI 2.57.0.
</Note>

## Prerequisites

- Python 3.11–3.13
- [uv](https://docs.astral.sh/uv/)
- A model-provider credential for the Pydantic AI agent
- A current Google Chrome installation for local browser mode

## Quickstart

<Steps>
  <Step title="Install dependencies">
Create a Python project and install Pydantic AI and the browser middleware:

```bash
mkdir pydantic-browser
cd pydantic-browser
uv init --python 3.11
uv add "pydantic-ai>=2.57,<3" "stagehand-middleware>=0.1.0,<0.2" "jsonschema>=4.23,<5"
```
  </Step>
  <Step title="Save the example">
Copy [agent.py](https://github.com/browserbase/stagehand/blob/main/packages/integrations/pydantic-ai/agent.py) into your project. It registers the browser tools with Pydantic AI and manages the browser session.
  </Step>
  <Step title="Configure the agent model">
The example uses an OpenAI model by default. Set the provider credential for the Pydantic AI agent:

```bash
export OPENAI_API_KEY="your-openai-api-key"
```

Set `PYDANTIC_AI_MODEL` to use another model supported by Pydantic AI (`provider:model-name`).
  </Step>
  <Step title="Choose the browser">
The integration uses Browserbase when `BROWSERBASE_API_KEY` is set, otherwise local Chrome. To select Browserbase explicitly:

```bash
export STAGEHAND_BROWSER="browserbase"
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```
  </Step>
  <Step title="Run a browser task">
```bash
uv run python agent.py \
  "Open https://example.com and report the page title."
```
  </Step>
</Steps>

## Configuration

| Variable | Purpose |
| --- | --- |
| `PYDANTIC_AI_MODEL` | Pydantic AI agent model. Defaults to `openai:gpt-6-sol`. |
| `OPENAI_API_KEY` | Credential for the example's default agent model. |
| `STAGEHAND_BROWSER` | Select `local` or `browserbase`. |
| `BROWSERBASE_API_KEY` | Required for Browserbase. |
| `STAGEHAND_HEADLESS` | Set to `true` for headless local Chrome. Defaults to `false`. |
| `STAGEHAND_MODEL` | Optional model for Stagehand AI methods called inside `run`. |
| `STAGEHAND_MODEL_API_KEY` | Optional credential for `STAGEHAND_MODEL`. |

## Structured output

Pass `--structured` to return a `PageReport` model with `title`, `url`, and `notes` instead of plain text.

## Keep the browser session alive

The example creates one Stagehand session and middleware instance around the complete agent run. Keep that lifetime when adapting it so snapshot IDs and page state survive across calls. Browser tools execute sequentially. The session and browser close when the run finishes or fails.

<Warning>
`run` executes model-authored JavaScript in the browser. Use Browserbase for untrusted tasks and review the [integration security boundary](/v4/integrations/agent-frameworks/overview#security-boundary).
</Warning>
