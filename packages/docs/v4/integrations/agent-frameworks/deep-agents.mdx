Use [`langchain-stagehand`](https://github.com/langchain-ai/langchain-browserbase) to add
Stagehand's `run`, `snapshot`, and `screenshot` tools to Deep Agents.

## Quickstart

Requires Python 3.11+, a model-provider key, and a Browserbase API key.

```bash
pip install "langchain-stagehand>=0.0.1,<0.1" "deepagents>=0.7,<1" "langchain-openai>=1,<2"
export OPENAI_API_KEY="your-openai-api-key"
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```

```python
import asyncio
import os

from deepagents import create_deep_agent
from langchain_stagehand import StagehandMiddleware
from stagehand import Stagehand, browserbase


async def main():
    browser = await browserbase.launch(api_key=os.environ["BROWSERBASE_API_KEY"])
    try:
        stagehand = await Stagehand.create(browser=browser)
        browser_middleware = StagehandMiddleware(stagehand=stagehand)
        agent = create_deep_agent(
            model="openai:gpt-5.6-luna",
            tools=browser_middleware.tools,
            middleware=[browser_middleware],
        )
        result = await agent.ainvoke({
            "messages": [{"role": "user", "content": "Open example.com and summarize the page."}]
        })
        print(result["messages"][-1].content)
    finally:
        await browser.close()


asyncio.run(main())
```

Pass `tools=browser_middleware.tools` so Deep Agents' default subagent also receives the browser
tools. The parent and subagent share the same browser; use separate clients for unrelated conversations.

For local Chrome, replace the browser launch with:

```python
from stagehand import local_browser

browser = await local_browser.launch(headless=False)
```

See the [adapter documentation](https://github.com/langchain-ai/langchain-browserbase#readme)
for configuration. The [repository examples](https://github.com/browserbase/stagehand/tree/main/packages/integrations/deepagents#run-the-examples)
include structured-output sports research and form filling.

## Managed Deep Agents

The managed example uses thread-scoped tools and Browserbase. It requires `DEEPAGENTS_MODEL`, its
provider key, `BROWSERBASE_API_KEY`, and either `STAGEHAND_API_URL` or `STAGEHAND_MODEL` with
`STAGEHAND_MODEL_API_KEY`. See [`.env.example`](https://github.com/browserbase/stagehand/blob/main/packages/integrations/deepagents/examples/managed/.env.example).

```bash
cd packages/integrations/deepagents/examples/managed
uv sync --locked
uv run mda dev .
uv run mda deploy .
```

Browser state persists while the managed worker is warm; reconnection after worker replacement
is not supported.

<Warning>
`run` executes model-authored JavaScript in the browser. Use Browserbase for untrusted tasks and
review the [integration security boundary](/v4/integrations/agent-frameworks/overview#security-boundary).
</Warning>
