Use [`langchain-stagehand`](https://github.com/langchain-ai/langchain-browserbase) to add
Stagehand's `run`, `snapshot`, and `screenshot` tools to Deep Agents.

## Install

Requires Python 3.11+ and a model-provider API key (`ANTHROPIC_API_KEY` for the example below).

```bash
pip install langchain-stagehand deepagents
```

## Add browser tools

[Configure a Stagehand client](https://github.com/langchain-ai/langchain-browserbase#browser-lifecycle)
for local Chrome or Browserbase, then pass that client as `stagehand`:

```python
from deepagents import create_deep_agent
from langchain_stagehand import StagehandMiddleware

middleware = StagehandMiddleware(stagehand=stagehand)
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=middleware.tools,
    middleware=[middleware],
)
```

Pass `tools=middleware.tools` so the default subagent also receives the browser tools.
Use `agent.ainvoke()` or `agent.astream()` to run the agent. See the
[adapter guide](https://github.com/langchain-ai/langchain-browserbase#readme) for complete setup
and browser cleanup.

## Repository examples

- [Local examples](https://github.com/browserbase/stagehand/tree/main/packages/integrations/deepagents#run-locally): sports research and form filling with structured output.
- [Managed Deep Agents](https://github.com/browserbase/stagehand/tree/main/packages/integrations/deepagents#develop-and-deploy-the-managed-agent): a deployment example with thread-scoped Browserbase tools and its own setup instructions.

<Warning>
`run` executes model-authored JavaScript in the browser. Use Browserbase for untrusted tasks and review the [integration security boundary](/v4/integrations/agent-frameworks/overview#security-boundary).
</Warning>
