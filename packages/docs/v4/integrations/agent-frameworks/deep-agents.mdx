Use [`langchain-stagehand`](https://github.com/langchain-ai/langchain-browserbase) to add
Stagehand's `run`, `snapshot`, and `screenshot` tools to Deep Agents. The same tools work with
local Chrome and remote Browserbase sessions. LangChain's [browser-use guide](https://docs.langchain.com/oss/python/deepagents/browser-use)
covers browser choices, use cases, and session scope.

## Install

Requires Python 3.11+ and a model-provider API key (`OPENAI_API_KEY` for the example below).

```bash
pip install langchain-stagehand deepagents langchain-openai
```

## Add browser tools

[Configure a Stagehand client](https://docs.langchain.com/oss/python/integrations/tools/stagehand#choose-the-browser)
for local Chrome or Browserbase, then pass that client as `stagehand`:

```python
from deepagents import create_deep_agent
from langchain_stagehand import StagehandMiddleware

middleware = StagehandMiddleware(stagehand=stagehand)
agent = create_deep_agent(
    model="openai:gpt-5.5-2026-04-23",
    tools=middleware.tools,
    middleware=[middleware],
)
```

Pass `tools=middleware.tools` so the default subagent also receives the browser tools.
Use `agent.ainvoke()` or `agent.astream()` to run the agent. See the
[Stagehand integration guide](https://docs.langchain.com/oss/python/integrations/tools/stagehand) for complete setup
and browser cleanup.

## Examples and managed agents

- [Local examples](https://github.com/browserbase/stagehand/tree/main/packages/integrations/deepagents#run-locally): sports research and form filling with structured output.
- [Managed Deep Agents browser use](https://docs.langchain.com/langsmith/python/managed-deep-agents-browser-use#browser-tools): use `define_browser` for platform-managed sessions and built-in `browser_*` tools, including human handoff.
- [Custom managed example](https://github.com/browserbase/stagehand/tree/main/packages/integrations/deepagents#managed-deep-agents): application-managed Stagehand tools with a Browserbase session per thread.

<Warning>
`run` executes model-authored JavaScript in the browser. Use Browserbase for untrusted tasks and review the [integration security boundary](/v4/integrations/agent-frameworks/overview#security-boundary).
</Warning>
